# 猜数字插件

用短会话实现猜数字游戏；命令检测到其他插件的活动会话时会拒绝开始或重开。每名用户在群聊或私聊上下文中分别拥有至多一个活动会话。

## 命令

<!-- manifest-command-aliases:start -->
| 命令别名 | 功能 |
| --- | --- |
| `/猜数字`、`/guess`、`/猜` | 开始或管理猜数字游戏 |
<!-- manifest-command-aliases:end -->

```text
/猜数字
/猜数字 简单
/猜数字 普通
/猜数字 困难
/猜数字 地狱
/猜数字 status
/猜数字 restart
/猜数字 help
```

英文难度别名为 `easy`、`normal`、`hard`、`hell`；短别名 `e`、`n`、`h` 也可使用。命令只接受一个完整参数，未知难度、多余参数、控制字符、超长输入和未闭合引号会被拒绝，不再静默回退为普通难度。

## 会话流程

1. 游戏开始后直接发送数字，不要重复命令前缀。
2. 发送 `状态`、`status`、`信息`、`info` 或 `?` 查看进度。
3. 发送 `退出`、`取消`、`exit`、`quit` 或 `q` 放弃游戏；这些退出词由框架统一处理。
4. `/猜数字 restart` 在检测到本插件旧游戏时才会替换；若当前是其他插件会话，会提示先退出，不会主动删除。
5. 会话 3 分钟无操作自动过期。

会话只保存目标、动态上下界、已用次数、历史和规范难度。剩余次数与提示范围均在读取时计算，不重复持久化派生状态。猜测输入限制为 64 字，只接受 1–4 位 ASCII 十进制数字；无效或越界输入不会消耗机会。

## 难度

| 难度 | 范围 | 机会 |
| --- | ---: | ---: |
| 简单 | 1–50 | 10 次 |
| 普通 | 1–100 | 7 次 |
| 困难 | 1–200 | 8 次 |
| 地狱 | 1–1000 | 10 次 |

随机目标不会写入日志。游戏进行中，框架按用户与群聊/私聊键串行提交每次会话更新。
