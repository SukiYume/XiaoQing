# 🔢 猜数字

`guess_number` 使用 Core Session 提供短会话猜数字游戏。每名用户在一个群聊或私聊作用域中最多拥有一个活动会话。

---

## ⌨️ 命令

<!-- manifest-command-aliases:start -->
| 功能 | 推荐入口 | Manifest 等价别名 |
| --- | --- | --- |
| 猜数字游戏 | `/猜数字` | `/guess` `/猜` |
<!-- manifest-command-aliases:end -->

| 用法 | 说明 |
| --- | --- |
| `/猜数字` | 按普通难度开始 |
| `/猜数字 简单` | 开始简单难度 |
| `/猜数字 普通` | 开始普通难度 |
| `/猜数字 困难` | 开始困难难度 |
| `/猜数字 地狱` | 开始地狱难度 |
| `/猜数字 status` | 查看当前进度 |
| `/猜数字 restart` | 结束本插件会话并按普通难度重开 |
| `/猜数字 help` | 显示本地帮助 |

难度别名：`easy`、`e`、`normal`、`n`、`hard`、`h`、`hell`、`nightmare`。状态别名：`状态`、`info`、`信息`。重开别名：`重新开始`、`重开`。

---

## 🔄 游戏流程

1. 使用命令选择难度并开始游戏；
2. 直接发送 ASCII 十进制数字进行猜测；
3. 发送 `状态`、`status`、`信息`、`info` 或 `?` 查看进度；
4. 发送 `退出`、`取消`、`exit`、`quit` 或 `q` 结束会话；
5. 连续 3 分钟（180 秒）空闲后，Core 自动结束会话。

活动会话属于其他插件时，猜数字命令会提示先结束当前会话。`restart` 仅替换本插件拥有的游戏。

---

## 🎮 难度

| 难度 | 目标范围 | 机会 |
| --- | ---: | ---: |
| 简单 | 1～50 | 10 次 |
| 普通 | 1～100 | 7 次 |
| 困难 | 1～200 | 8 次 |
| 地狱 | 1～1000 | 10 次 |

猜测输入长度上限为 64 个字符，数字范围为 1～4 位。格式或范围异常的输入会保留当前机会数。

---

## 💾 会话状态

Session 保存目标、动态上下界、已用次数、猜测历史和规范难度。剩余次数与提示范围在读取时计算。胜利、机会用尽、显式退出、超时或状态校验异常会结束游戏。

游戏目标由系统随机源生成，并保留在日志边界之外。Core 按用户和聊天作用域串行提交会话更新。插件运行配置、凭据、网络请求、文件和定时任务均为空集。

---

## 🩺 排障

| 现象 | 处理方式 |
| --- | --- |
| 提示已有其他会话 | 发送 `退出`，再开始猜数字 |
| 数字输入持续被拒绝 | 使用当前提示范围内的 ASCII 整数 |
| 游戏已过期 | 重新发送 `/猜数字` |
| `restart` 提示会话归属异常 | 先结束当前 Core Session |
