# 猜数字

1. 发送 `/猜数字`，或附带 `简单`、`普通`、`困难`、`地狱` 开始游戏。
2. 会话开始后直接发送数字，不要重复命令前缀。
3. 发送 `状态`/`info` 查看进度，发送 `退出`/`取消` 放弃。
4. `/猜数字 restart` 会结束旧会话并重新开始；`/猜数字 status` 可从命令入口查询。

会话按用户和群/私聊上下文隔离，3 分钟无操作自动过期。Dispatcher 只在存在本插件活跃会话时把普通后续消息交给游戏处理器。

难度范围和机会数：简单 1–50/10 次，普通 1–100/7 次，困难 1–200/8 次，地狱 1–1000/10 次。
