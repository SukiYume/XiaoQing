# Earthquake 地震快讯插件

从“[中国地震台网速报](https://www.weibo.com/ceic)”微博读取最近的地震快讯。手动命令用于查询；定时任务每 5 分钟检查一次，仅向默认群组投递 4.0 级及以上的新快讯。

## 命令

<!-- manifest-command-aliases:start -->
| 命令别名 | 功能 |
| --- | --- |
| `/earthquake`、`/地震` | 查询最近一条地震快讯 |
<!-- manifest-command-aliases:end -->

支持以下参数：

```text
/earthquake
/earthquake latest
/earthquake help
```

- 空参数、`latest` 和 `最新`：查询最近一条有效快讯，不限震级。
- `help`、`h` 和 `帮助`：显示帮助。
- 未知子命令、多余参数、控制字符和未闭合引号会被拒绝，不会静默当作查询执行。

手动查询不会推进定时任务游标，也不会影响下一次自动通知。

## 定时投递

插件清单配置为每 5 分钟运行一次 `scheduled`：

- 只投递震级不低于 4.0 的新快讯；低震级快讯仍会被标记为已扫描。
- 投递目标来自 XiaoQing 的全局默认群组；未配置目标时不会发送，也不会越过待投递游标。
- 每个目标单独记录完成状态。进程退出或部分群组发送失败后，会先重试未完成目标，再继续拉取新数据。
- 全部目标完成后才提交微博游标，降低“游标已前进但消息未送达”的风险。

## 本地状态

运行数据位于插件数据目录，并由仓库的 `.gitignore` 排除：

| 文件或目录 | 用途 |
| --- | --- |
| `earthquake.json` | 当前微博游标 |
| `earthquake.checkpoint.json` | 游标恢复检查点 |
| `earthquake_delivery.json` | 待投递事件及逐目标进度 |
| `EarthquakeFigures/` | 经格式、尺寸和完整性校验后的图片缓存 |

游标文件只接受有界普通 JSON 文件；损坏文件会被原子移入同目录的 `*.corrupt-*` 取证副本，再从有效检查点恢复。图片缓存按内容哈希命名，最多 64 项、64 MiB，且会清理超过 30 天的旧项。

## 网络与数据边界

- 索引请求使用微博移动端访客接口，并限制响应类型、压缩比例、解码大小、JSON 深度、节点数和卡片总数。
- 图片只允许从 `wx1` 至 `wx4.sinaimg.cn` 的 HTTPS 地址下载，最大 8 MiB；MIME、实际格式、容器结尾、帧数、尺寸、像素数和解码内存必须全部通过校验。
- 外部微博正文会移除脚本、样式、HTML 标签和控制字符；单条畸形卡片会被跳过，不会污染通知内容。

## 可靠性说明

微博移动端访客接口不是承诺稳定的公开数据 API，可能因访客验证、限流或页面改版临时不可用。因此本插件提供的是尽力而为的消息提醒，不应作为唯一的地震预警或应急信息来源。中国地震台网速报也曾在[官方微博说明](https://www.weibo.com/1904228041/PuwQo3tUq)微博发布可能不稳定；需要应急判断时，请同时使用其官方 App、微信服务号或小程序等渠道复核。

插件本身不需要密钥；手动查询需要可访问微博和新浪图片域名，自动投递还需要配置至少一个全局默认群组。
