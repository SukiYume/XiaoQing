# Color 颜色查询插件

查询随发行版提供的 526 种中国传统色、恒星光谱色，以及当前群聊或私聊作用域的管理员自定义色。
插件支持按名称、RGB、HEX、CMYK 和名称关键词查找，并可生成有界缓存的 PNG 色卡。

## 命令入口

<!-- manifest-command-aliases:start -->
| 推荐入口 | manifest 等价别名 |
|---|---|
| `/color` | `/颜色`、`/色彩` |
<!-- manifest-command-aliases:end -->

三个入口执行完全相同的命令：

```text
/color -n 乳白
/颜色 -n 杏仁黄 -p
/色彩 -a 红
```

### 中国传统色与自定义色

| 参数 | 长参数 | 作用 |
|---|---|---|
| `-n` | `--name` | 按完整名称查询 |
| `-r` | `--rgb` | 按 RGB 查询，支持空格或逗号分隔 |
| `-x` | `--hex` | 按三位或六位 HEX 查询，单个 `#` 可省略 |
| `-c` | `--cmyk` | 按 CMYK 查询，支持空格或逗号分隔 |
| `-a` | `--accord` | 按颜色名称中的字面子串搜索，最多展示 20 条 |
| `-p` | `--picture` | 为名称/RGB/HEX/CMYK 查询附加色卡 |
| `-w` | `--write` | Bot 全局管理员添加当前作用域自定义色 |
| `-d` | `--delete` | Bot 全局管理员删除当前作用域自定义色 |

```text
/color -r 255 87 51
/color -r 255,87,51 -p
/color -x #FF5733
/color -c 0 100 100 0
/color -w 品牌色 45 134 255
/color -w 主题色 #FF6B6B
/color -d 品牌色
```

一次命令只能选择一种主操作。未知选项、重复的长短别名、多余位置参数、带值的 `-p`、控制字符、
非 ASCII 数字、超长参数和越界通道值都会被拒绝；插件不会按优先级悄悄忽略冲突选项。自定义颜色
名称是单个不含空白的 token，最长 64 个字符。

### 恒星光谱色

```text
/color -s O5V
/color -s G2V
/color -t
/color -t M
```

`-t/--spectype` 列出不重复的光谱型，字面前缀/子串不会作为正则表达式执行。源表按有效温度网格
列出 105 行，同一粗粒度光谱型可能对应多行；精确查询保持源表顺序并展示第一条温度采样，同时
说明该类型的温度采样范围。

恒星色数据来自 Harre 与 Heller 的论文 *Digital color codes of stars* 表 5：
[DOI 10.1002/asna.202113868](https://doi.org/10.1002/asna.202113868)，
[arXiv:2101.06254](https://arxiv.org/abs/2101.06254)。表中的线性 RGB 只保留三位小数，而 HEX
由更高精度值生成，所以加载器分别验证范围和格式，不用三位小数反推 HEX 后制造误报。

### 帮助

以下写法都显示帮助，不读取颜色资产，也不创建图片目录：

```text
/color
/color help
/color -h
/color --help
/color -l
/color --list
```

## 数据和作用域

### `color.json`

- 固定数组，共 526 条，字段为 `name`、`pinyin`、`RGB`、`hex`、`CMYK`。
- 加载时验证文件类型、字节数、条目数、名称唯一性、字段类型、通道范围，以及 RGB/HEX 一致性。
- 历史资产中 8 条 RGB/HEX 不一致记录已按显示用 HEX 规范化 RGB；回归测试锁定全部 526 条的
  结构和一致性。
- 两个不同色名可以共享同一数字颜色（当前“铅灰”和“中灰”如此），这不属于重复名称。

### `stellar_colors.txt`

- 105 行太阳金属丰度主序星温度网格，列为 `SpT Teff log(g) RGB Hex`。
- 使用标准库的有界解析器，不再为这份小表加载 pandas。
- 文件必须是非链接普通文件，且满足表头、行数、行长、数值范围和 HEX 格式约束。

### 自定义颜色

只有当前事件中经过核心认证的 Bot 全局管理员可以写入或删除，普通成员可以读取同一作用域的
自定义颜色。群聊优先使用群作用域，私聊使用当前用户作用域：

```text
data/custom_colors_group_<群号>.json
data/custom_colors_private_<用户号>.json
```

缺少合法群号和用户号时失败关闭，不再回退到所有人共享的 `custom_colors.json`。每个作用域最多
200 条、256 KiB；读写均在进程锁内完成，结构损坏或手工越界文件不会被空数组覆盖。回调没有
实际改变内容时不会重复写盘。新增名称不能覆盖内置色或本作用域已有自定义色。

## 图片缓存

色卡以“规范名称 + RGB”的 SHA-256 内容身份命名，避免用户文本进入文件名。缓存使用核心有界
文件缓存：最多 256 项、总计 32 MiB、保留 30 天；读取、写入和 LRU 回收均在专用目录锁内完成。
日志只记录操作类型、命中状态、数量或字节数，不记录用户查询、自定义名称或完整路径。

图片功能需要 matplotlib 和 numpy。缺少依赖时文字查询仍可用；插件不会在事件循环内同步渲染。

## 转换规则

- RGB：三个 0-255 的精确整数；布尔、浮点、全角数字和隐式字符串转换不接受。
- CMYK：四个 0-100 的精确整数。
- HEX：仅接受 `RGB`、`#RGB`、`RRGGBB` 或 `#RRGGBB`；多余 `#` 和非 ASCII 十六进制字符拒绝。
- 自定义颜色的 CMYK 由 RGB 按标准无设备公式换算并四舍五入到整数百分比。

## 运行环境

- Python `>=3.10,<3.14`（与项目元数据一致）。
- 基础颜色和恒星查询只使用标准库与 XiaoQing 核心。
- matplotlib/numpy 仅用于可选色卡渲染。
