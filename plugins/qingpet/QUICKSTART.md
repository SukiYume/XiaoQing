# 🚀 QingPet 快速开始

本指南面向首次部署者，用一组 QQ 群命令完成权限、数据库、养成、社交和定时任务的基础验收。完整玩法见 [README.md](README.md)。

---

## 🚀 1. 启动项目

QingPet 随 XiaoQing 加载。在已安装项目依赖的环境中运行：

```bash
python main.py
```

启动日志应包含 QingPet Manifest 加载和 SQLite 初始化结果。数据库路径为：

```text
data/qingpet/qingpet/qingpet.db
```

---

## ✅ 2. 验证群管理权限

由当前群管理员、群主或 Bot 管理员发送：

```text
/宠物 管理 开启
/宠物 管理 配置 查看
```

配置返回应包含 `enabled`、经济倍率、衰减倍率、交易开关、自然触发开关和活动开关。

---

## 🚀 3. 完成首次养成

使用普通群成员账号依次发送：

```text
/宠物 领养 小白
/宠物 状态
/宠物 喂食 apple
/宠物 清洁
/宠物 玩耍
```

预期结果：

- 领养创建一颗宠物蛋；
- 状态卡显示五项属性、阶段、经验和资产；
- 三个照料动作分别更新状态、经验、任务进度与资产账本；
- 短时间重复操作返回冷却提示。

蛋累计 10 经验后孵化。后续进化同时使用经验、年龄和照顾评分。

---

## ✅ 4. 验证道具

```text
/宠物 商店
/宠物 购买 apple 2
/宠物 背包
/宠物 装扮 商店
/宠物 装扮 查看
```

购买数量范围为 1～99。商品输出是当前价格、货币和库存规则的运行时依据。

---

## ✅ 5. 验证社交

准备两个已领养宠物的群成员账号：

```text
/宠物 查看 @对方QQ
/宠物 互访 @对方QQ
/宠物 摸摸 @对方QQ
/宠物 送礼 @对方QQ apple 1
/宠物 留言 @对方QQ 今天也要开心
/宠物 排行 care_score
```

预期结果包括双方数据按群隔离、库存与奖励原子更新、留言内容校验和排行榜刷新。

---

## ✅ 6. 验证玩法与交易

```text
/宠物 游戏 骰子
/宠物 任务
/宠物 群任务
/宠物 活动
/宠物 展示
```

交易市场由群管理员开启：

```text
/宠物 管理 配置 设置 trade_enabled true
/宠物 交易 挂单 apple 1 20
/宠物 交易 列表
```

使用第二个账号购买列表中的订单，再检查双方背包、金币和群统计。

---

## ✅ 7. 验证管理员操作

```text
/宠物 管理 日志 20
/宠物 管理 统计
/宠物 管理 活动 创建 feed 10 50 全群喂食挑战
/宠物 管理 公告 展示会 首次展示会
```

重置与删除要求同一条命令附带确认词：

```text
/宠物 管理 重置 @测试账号 确认
/宠物 管理 删除 @测试账号 确认
```

请使用专门的测试账号验证破坏性管理命令。

---

## ✅ 8. 验证定时任务

保持 Bot 运行并观察日志与数据：

| 时间 | 验证点 |
| --- | --- |
| 下一分钟 | 状态衰减与展示会结算任务执行 |
| 下一 5 分钟边界 | 到期交易挂单清理任务执行 |
| 次日 00:00 | 每日计数重置与宠物年龄增长 |
| 周一 10:00 | 周排行奖励与称号结算 |

生产数据验证前先备份 `qingpet.db`、`qingpet.db-wal` 和 `qingpet.db-shm`。

## 📌 9. 自动化回归

```bash
python -m ruff check plugins/qingpet tests/plugins/test_qingpet*.py
python -m mypy plugins/qingpet
python -m pytest -q tests/plugins -k qingpet -n 2
```

全部检查通过后，再使用 `/宠物 帮助` 在目标 QQ 客户端确认手机端分页和消息长度。
