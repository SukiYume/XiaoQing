# QingPet 快速开始

QingPet 已随项目安装，不需要单独下载。以下示例均在 QQ 群中执行；管理命令必须
由当前群管理员、群主或 Bot 管理员发送。

## 1. 启用并确认配置

```text
/宠物 管理 开启
/宠物 管理 配置 查看
```

新建群配置默认启用宠物系统，但显式执行一次“开启”可以确认权限和数据库写入均
正常。交易市场默认关闭，如需使用可执行：

```text
/宠物 管理 配置 设置 trade_enabled true
```

## 2. 完成第一次养成循环

```text
/宠物 领养 小白
/宠物 状态
/宠物 喂食 apple
/宠物 清洁
/宠物 玩耍
```

领养后得到一颗蛋。蛋累积 10 经验后孵化；之后的进化同时受经验、年龄和照顾评分
影响。各项行为都有冷却和每日次数限制，操作过快时会被限流或降低收益。

常用进阶操作：

```text
/宠物 训练 体力
/宠物 探索 森林
/宠物 睡觉
/宠物 起床
/宠物 治疗 medicine
/宠物 召回
/宠物 改名 新名字
```

## 3. 使用商店、背包和装扮

```text
/宠物 商店
/宠物 购买 cake 2
/宠物 背包
/宠物 装扮 商店
/宠物 装扮 购买 red_hat
/宠物 装扮 穿戴 red_hat
/宠物 装扮 查看
/宠物 装扮 卸下 帽子
```

购买数量必须是 1～99 的整数。装扮可使用金币或友情点计价，具体价格以商店输出
为准。

## 4. 参与社交与群玩法

```text
/宠物 查看 @123456789
/宠物 互访 @123456789
/宠物 摸摸 @123456789
/宠物 送礼 @123456789 apple 2
/宠物 留言 @123456789 今天也要开心
/宠物 留言
/宠物 排行 care_score
```

互访、送礼、留言和小游戏都有限频。消息平台重投同一条互访或小游戏事件时，插件
会重放首次结果，不会重复发放金币或扣除精力。

```text
/宠物 游戏 猜拳 石头
/宠物 游戏 骰子
/宠物 游戏 赛跑 @123456789
/宠物 任务
/宠物 任务 领取
/宠物 群任务
/宠物 群任务 领取
/宠物 活动
/宠物 称号
/宠物 展示
```

交易市场开启后可使用：

```text
/宠物 交易 列表
/宠物 交易 挂单 apple 2 40
/宠物 交易 购买 1
/宠物 交易 撤单 1
```

## 5. 管理群配置和用户

```text
/宠物 管理 配置 设置 economy_multiplier 2.0
/宠物 管理 配置 设置 decay_multiplier 0.5
/宠物 管理 封禁 @123456789 7
/宠物 管理 解封 @123456789
/宠物 管理 日志 50
/宠物 管理 统计
```

重置和删除属于破坏性操作，必须在同一条命令中带确认词：

```text
/宠物 管理 重置 @123456789 确认
/宠物 管理 删除 @123456789 确认
```

创建行为活动和展示会：

```text
/宠物 管理 活动 创建 feed 30 100 全群喂食挑战
/宠物 管理 公告 展示会 春季展示会
/宠物 管理 公告 结束展示会
```

活动类型仅支持 `feed`、`clean`、`play`、`train` 和 `explore`。

## 6. 私聊规则

- 只有一只宠物时，背包、商店、装扮和大多数社交查询会自动定位到对应群。
- 同一账号在多个群有宠物时，涉及他人的命令应回到目标群执行。
- 喂食、训练、任务等自身命令可在私聊参数开头指定群号，例如：

```text
/宠物 喂食 123456 apple
/宠物 任务 123456 领取
```

`/宠物 状态` 在未指定群号时会列出该账号在所有群中的宠物。

## 7. 进化门槛

| 当前阶段 | 经验门槛 | 年龄门槛 | 结果 |
|---|---:|---:|---|
| 蛋 | 10 | 无 | 幼年（破壳） |
| 幼年 | 50 | 7 天 | 成长期，形态受照顾评分影响 |
| 成长期 | 100 | 21 天 | 成熟期，形态受照顾评分影响 |
| 成熟期 | 150 | 60 天 | 老年 |

照顾评分是饥饿、心情、清洁、精力和健康五项属性的平均比例。

## 8. 常见问题

**为什么操作失败？**

通常是冷却未结束、精力或道具不足、达到每日上限、群功能未开启，或当前宠物处于
睡眠、生病、旅行等不允许互动的状态。

**宠物会永久死亡吗？**

当前玩法采用温和处理：健康过低会生病，长期照顾不足可能触发旅行；可以使用召回
命令提前找回。

**真实数据库在哪里？**

正常加载时位于 `data/qingpet/qingpet/qingpet.db`。该目录属于本地运行时
数据，不要提交，也不要用测试或清理脚本覆盖。

完整命令与事务说明见 [README.md](README.md)。
