# 🐾 QingPet

QingPet 是按 QQ 群隔离数据的宠物养成插件。群成员可以领养、照料、训练和装扮宠物，并参与互访、送礼、小游戏、任务、交易与展示会；群管理员负责配置、活动和插件内用户管理。

---

## 🐾 交易市场

群配置 `trade_enabled` 控制交易市场：

```text
/宠物 交易 列表
/宠物 交易 挂单 <道具ID> <数量> <价格>
/宠物 交易 购买 <订单号>
/宠物 交易 撤单 <订单号>
```

挂单会把道具移入托管状态。购买、撤单和到期退还均在事务中同时处理订单、库存、余额和资产账本。

## 🐾 成长规则

| 当前阶段 | 经验门槛 | 年龄门槛 | 下一阶段 |
| --- | ---: | ---: | --- |
| 蛋 | 10 | 0 天 | 幼年 |
| 幼年 | 50 | 7 天 | 成长期 |
| 成长期 | 100 | 21 天 | 成熟期 |
| 成熟期 | 150 | 60 天 | 老年 |

幼年期和成长期的形态由照顾评分影响。照顾评分取饥饿、心情、清洁、精力和健康五项属性的平均比例。

状态值随时间衰减，托管期间采用减半衰减。健康过低会进入生病状态，长期照顾偏低可能触发旅行；治疗和召回提供恢复路径。

## 🔐 经济与风控

- 金币和友情点余额以 `users` 表为准；
- 全部受控资产变化同步写入 `asset_ledger`；
- 群统计会计算余额与资产账本的差异；
- 关键行为受冷却、每日次数、群响应限频和重复行为收益衰减约束；
- 互访、小游戏、治疗、交易、任务与活动奖励采用原子事务或幂等标识；
- 昵称、留言和展示文本执行长度、控制字符与敏感词校验。

## ✨ 私聊定位

账号只有一只宠物时，背包、商店、装扮和自身操作会自动定位对应群。账号在多个群拥有宠物时，自身操作可在参数开头指定群号：

```text
/宠物 喂食 123456 apple
/宠物 任务 123456 领取
```

`/宠物 状态` 在省略群号时会列出该账号的全部群宠物。涉及其他成员的社交与群玩法在目标群执行。

## 🔐 数据与内部边界

正常加载时，SQLite 数据库位于：

```text
data/qingpet/qingpet/qingpet.db
```

一个 `Database` 组合多个 repository mixin，共享同一个 SQLite 文件、连接生命周期和事务边界：

| 模块 | 职责 |
| --- | --- |
| `services/database.py` | 组合入口、线程连接和关闭生命周期 |
| `services/database_schema.py` | 表、索引、migration 和约束 |
| `services/database_identity.py` | 用户、宠物、背包和群配置 |
| `services/database_community.py` | 任务、活动、留言、交易和展示会 |
| `services/database_actions.py` | 配额、资产和宠物动作事务 |
| `services/database_scheduler.py` | 周期结算、到期清理和经济快照 |
| 领域 service | 宠物、社交、道具、经济、用户和管理用例 |

运行数据由插件和管理员备份流程管理。

## 🩺 排障

| 现象 | 检查项 |
| --- | --- |
| 行为进入冷却 | 查看命令返回的剩余时间，随后再次操作 |
| 收益下降 | 检查当日次数和重复行为风控 |
| 交易入口关闭 | 由群管理员设置 `trade_enabled=true` |
| 私聊提示群定位 | 在参数开头加入群号，或回到目标群执行 |
| 管理命令权限异常 | 核对 OneBot 事件中的群角色与 Core 管理员配置 |
| 数据库异常 | 停止 Bot，备份数据库与 WAL 文件，再按日志定位事务 |
