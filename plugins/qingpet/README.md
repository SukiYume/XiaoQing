# QingPet - QQ 群宠物养成系统

QingPet 是一个按群隔离数据的宠物养成插件。群成员可以领养、照料和训练宠物，
参与互访、送礼、小游戏、群任务、交易与展示会；群管理员负责功能开关、活动和
违规处理。

## 用户命令

入口别名为 `/qingpet`、`/宠物`、`/pet`；下文统一使用 `/宠物` 展示。

### 领养与照料

- `/宠物 领养 <名字>`：领养一颗宠物蛋。
- `/宠物 状态 [群号]`：查看宠物属性、装扮、金币、友情点和称号。
- `/宠物 喂食 [食物 ID/名称]`：默认使用苹果，也可指定其他食物。
- `/宠物 清洁`、`/宠物 玩耍`：改善状态并推进任务。
- `/宠物 睡觉`、`/宠物 起床`：进入或结束休息状态。
- `/宠物 训练 [体力/敏捷/智力]`：消耗精力并获得经验。
- `/宠物 探索 [森林/海边/山洞/废墟]`：触发随机事件与掉落。
- `/宠物 治疗 [药品 ID/名称]`：原子扣除药品并恢复健康。
- `/宠物 召回`：支付金币提前召回旅行中的宠物。
- `/宠物 改名 <新名字>`：修改宠物名称。

### 道具与装扮

- `/宠物 商店`、`/宠物 背包`：查看商品与库存。
- `/宠物 购买 <道具 ID/名称> [数量]`：数量必须是 1～99 的整数。
- `/宠物 使用 <道具 ID/名称>`：手动使用加速卡或托管券。
- `/宠物 装扮 商店`、`/宠物 装扮 查看`：查看装扮商品与当前穿戴。
- `/宠物 装扮 购买 <ID>`、`/宠物 装扮 穿戴 <ID>`：购买并穿戴装扮。
- `/宠物 装扮 卸下 <帽子/衣服/饰品/背景>`：卸下指定槽位。

### 社交与玩法

- `/宠物 查看 @QQ号`：查看同群用户的宠物卡片。
- `/宠物 互访 @QQ号`、`/宠物 摸摸 @QQ号`：执行有限频的轻量互动。
- `/宠物 送礼 @QQ号 <道具> [数量]`：向同群用户赠送道具。
- `/宠物 留言 @QQ号 <内容>`：留言；不带参数时查看自己收到的留言。
- `/宠物 排行 [care_score/intimacy/experience/coins]`：查看群排行榜。
- `/宠物 游戏 猜拳 <石头/剪刀/布>`、`/宠物 游戏 骰子`、
  `/宠物 游戏 赛跑 @QQ号`：参与小游戏。
- `/宠物 任务 [领取]`、`/宠物 群任务 [领取]`：查看或领取任务奖励。
- `/宠物 活动 [领取 <活动 ID>]`：查看活动或领取已完成活动的奖励。
- `/宠物 称号`：查看当前称号并检查新称号。
- `/宠物 展示 [投票 @QQ号]`：查看展示会或为其他宠物投票。
- `/宠物 交易 列表/挂单/购买/撤单`：使用受控交易市场；该功能默认关闭。

使用 `/宠物 帮助` 查看分类目录，也可使用 `/宠物 帮助 基础`、`进阶`、`道具`、
`社交`、`玩法` 或 `管理` 直接查看某一类命令。

## 成长、经济与一致性

- 蛋在经验达到 10 后孵化。
- 幼年期需要 50 经验且年龄达到 7 天；成长期需要 100 经验且年龄达到 21 天；
  成熟期需要 150 经验且年龄达到 60 天。照顾评分会影响幼年期和成长期的进化形态。
- 饥饿、心情、清洁、精力和健康按时间衰减；托管期间衰减减半。
- 关键操作同时受冷却、每日次数、群级响应限频和反脚本收益衰减约束。
- 金币与友情点的当前余额以 `users` 表为准，所有受控资产变更同时写入
  `asset_ledger`，群统计会报告账本差异而不会自动篡改余额。
- 互访、小游戏、治疗、交易、任务和活动奖励使用事务或幂等请求标识，失败或消息
  重投不会留下半完成状态或重复发放资产。

## 管理命令

- `/宠物 管理 开启`、`/宠物 管理 关闭`：切换当前群的插件状态。
- `/宠物 管理 配置 查看`：查看群级配置。
- `/宠物 管理 配置 设置 <key> <value>`：修改允许公开配置的字段。
- `/宠物 管理 重置 @QQ号 确认`：重置目标宠物及相关冷却。
- `/宠物 管理 删除 @QQ号 确认`：删除目标宠物及关联数据。
- `/宠物 管理 封禁 @QQ号 <天数>`、`/宠物 管理 解封 @QQ号`：管理插件内权限。
- `/宠物 管理 日志 [1～100]`、`/宠物 管理 统计`：查看审计记录和群统计。
- `/宠物 管理 活动 创建 <类型> <目标数> <奖励金币> [标题]`：创建群活动；类型为
  `feed`、`clean`、`play`、`train` 或 `explore`。
- `/宠物 管理 公告 展示会 [标题]`、`/宠物 管理 公告 结束展示会`：管理展示会。

管理权限只接受 core 根据当前已认证事件签发的主体，不读取插件自建管理员名单。

## 群级配置

| 配置项 | 说明 | 默认值 |
|---|---|---|
| `enabled` | 是否启用宠物系统 | `true` |
| `economy_multiplier` | 行为金币倍率，范围 0.1～10.0 | `1.0` |
| `decay_multiplier` | 状态衰减倍率，范围 0.1～10.0 | `1.0` |
| `trade_enabled` | 是否开放玩家交易 | `false` |
| `natural_trigger_enabled` | 是否允许自然语言触发 | `false` |
| `activity_enabled` | 是否推进群活动 | `true` |

## 定时任务

| 任务 | 周期 | 职责 |
|---|---|---|
| `qingpet_decay` | 每分钟 | 应用状态衰减并清理旧限频记录 |
| `qingpet_pet_show_settlement` | 每分钟 | 原子结算到期展示会 |
| `qingpet_trade_expiry` | 每 5 分钟 | 退还到期挂单中的托管道具 |
| `qingpet_daily_reset` | 每天 00:00 | 原子重置每日计数并增加宠物年龄 |
| `qingpet_weekly_activity` | 每周一 10:00 | 原子结算周排行奖励和“本周之星”称号 |

## 数据与代码结构

正常由插件管理器加载时，SQLite 数据库位于
`data/qingpet/qingpet/qingpet.db`。这是本地运行时目录，不应提交，
也不应在代码清理时读取或改写真实用户数据。

- `commands/`：命令解析与用户提示。
- `models/`：宠物、用户、背包和群配置模型。
- `services/`：领域服务、事务与 SQLite 持久化。
- `utils/`：常量、时间、格式化、校验与路由。
- `plugin.json`：入口、命令触发词和五个定时任务。
