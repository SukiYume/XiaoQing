# URL Parser 插件

自动解析消息中的 URL，生成网页摘要预览。

## 触发方式

该插件没有显式命令；当消息里包含 URL 且没有被其他命令处理时，会自动尝试解析。

## 解析内容

- 标题
- 描述
- 预览图片

如果目标网页提供 `og:image` 或 `twitter:image`，插件会在文字摘要后附带实际图片消息段。

## 支持范围

- 通用网页
- GitHub
- arXiv
- 其他能返回常见 Open Graph / Twitter Card 元数据的站点

## 注意事项

- 当前实现依赖页面返回的 HTML 元信息。
- 某些网站如果限制抓取，可能拿不到摘要或图片。
- 为了避免阻塞，HTML 解析会在线程池中完成。
