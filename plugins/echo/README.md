# Echo 插件

一个刻意保持最小规模的示例插件，用于验证命令分发、消息段返回和统一错误边界。

## 命令

<!-- manifest-command-aliases:start -->
| 命令别名 | 功能 |
| --- | --- |
| `/echo`、`/回显` | 回显文本 |
| `/hello`、`/你好` | 使用当前 QQ 号打招呼 |
<!-- manifest-command-aliases:end -->

```text
/echo 你好世界
/回显 支持中文别名
/hello
/你好
```

## 行为边界

- `/echo` 去除文本首尾空白后再回显；空文本显示帮助。
- 回显文本最多 3000 个字符，与 XiaoQing 的单条 QQ 文本上限一致。
- 文本可以包含换行和制表符；其他 C0/C1 控制字符会被拒绝。
- `/hello` 不接受额外参数，只显示经过正整数校验的当前 QQ 号；缺失或畸形 ID 显示“未知用户”。
- 未知命令返回固定提示，不把未经验证的命令内容复制到公开响应或日志。

插件没有配置、密钥、网络请求、持久状态或定时任务。日志只记录已接受回显文本的字符数，不记录正文。

## 开发参考

本插件只保留框架必需的 `handle()` 入口。帮助文本使用常量；两段私有逻辑分别承担控制字符校验和 QQ 号规范化，不提供空初始化函数或单纯转发包装。新插件可以参考其消息返回和公开错误处理方式，但应按自身需求增加参数解析、权限、I/O 与状态边界。
