# 天文学中英词典

插件内置中国天文学会天文学名词审定委员会发布的“英汉天文学名词数据库”
`r241020` 下载版，离线提供中英双向查询，不需要 pandas 或联网请求。

## 命令

- `/dict galaxy`：英译中模糊查询。
- `/dict 星系`：中译英模糊查询。
- `/dict -e "fast radio burst"`：精确匹配完整源词。
- `/dict -n 20 star`：最多显示 20 条；数量必须是 `1` 至 `100` 的 ASCII 整数。
- `/dict -- -example`：`--` 后的内容一律作为查询词，可查询以连字符开头的文本。
- `/dict help`：显示帮助。

`-e`/`--exact` 和 `-n`/`--num` 可放在查询词前后，但同一类选项不能重复。
未知选项、缺失数量、未闭合引号、控制字符和越界参数会直接返回明确错误，不会静默改用默认值。
模糊查询先将查询按空白分词，再要求每个关键词都出现在同一个源词中；查询包含中日韩统一表意
文字时使用中译英词典，否则使用英译中词典。

## 发行资产

- `assets/astrodict_ec.txt`：英译中，30,094 行映射。
- `assets/astrodict_ce.txt`：中译英，26,770 行映射。
- `assets/manifest.json`：来源版本、原始压缩包及成员哈希、打包后字节数、行数和 SHA-256。

行数是双向映射记录数，不等同于网站展示的唯一数据库词条数。发行文件为 UTF-8、无表头、
TAB 分隔的两列文本。打包过程只移除官方文件的 UTF-8 BOM、统一为 LF，并清理 13 条记录的字段
首尾空白；除这些格式空白外，词条顺序和文字内容保持官方 `r241020` 版本一致。

加载时会拒绝链接或非常规文件，并在解析前核对 manifest 版本、文件名、硬大小上限、精确字节数
和 SHA-256；随后核对 UTF-8、两列结构、行数、字段长度、控制字符和重复记录。每份文件只读取
一次，解析结果按文件时间指纹缓存；文件变化后会进入新的缓存代际。
