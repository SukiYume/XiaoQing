# 📖 天文学中英词典

`dict` 使用随发行版提供的“英汉天文学名词数据库”`r241020` 数据，离线完成中英双向查询。

---

## ⌨️ 命令

<!-- manifest-command-aliases:start -->
| 功能 | 推荐入口 | Manifest 等价别名 |
| --- | --- | --- |
| 天文学词典 | `/dict` | `/词典` `/字典` |
<!-- manifest-command-aliases:end -->

| 用法 | 说明 |
| --- | --- |
| `/dict galaxy` | 直接英译中，完整词和前缀词优先 |
| `/dict 星系` | 直接中译英，完整词和前缀词优先 |
| `/dict "fast radio burst" --exact` | 只看完整源词；未命中时给出相近词条 |
| `/dict galaxy --page 2` | 查看第 2 页 |
| `/dict star --size 20 --page 3` | 每页显示 20 条并查看第 3 页 |
| `/dict -- -example` | 把 `--` 后的内容作为查询词 |
| `/dict help` | 显示本地帮助 |

推荐直接输入词汇，只有需要收窄或翻页时才添加长参数。`--exact`、`--page` 和 `--size` 可位于查询词前后；原有 `-e`、`-p`、`-n`、`--num` 继续兼容，`--page-size` 与 `--size` 等价。每页默认 10 条；结果会标明查询方向、总数、当前页和总页数，并给出可复制执行的上一页/下一页命令。翻页命令完整携带查询条件，不依赖用户或群会话状态。

模糊查询会按空白分词，并要求全部关键词出现在同一个源词中。结果依次优先显示原样完整匹配、忽略大小写的完整匹配、前缀匹配、词边界匹配和普通包含匹配，同等级中短词优先。例如 `/dict galaxy` 的首条结果为 `galaxy → 星系`。精确查询缺少完整匹配时，会列出最多 5 条模糊建议，并提供普通查询命令。

包含中日韩统一表意文字的查询使用中译英数据，其余查询使用英译中数据。`help` 与 `帮助` 打开帮助，`list`、`l` 和 `h` 按普通词汇查询。查询词以连字符开头时，可在它前面加 `--` 停止选项解析。

---

## 🔐 输入边界

- 整体参数长度上限为 512 个字符；
- 查询词长度上限为 256 个字符；
- 每页条数接受 1～100 的 ASCII 整数；
- 页码接受 1～50,000 的 ASCII 整数，并在查询后按实际总页数再次校验；
- 引号采用 Shell 风格配对规则；
- 参数类别、重复选项、控制字符和资源字段均执行严格校验。

## 💾 发行资产

| 文件 | 内容 |
| --- | --- |
| `plugins/dict/assets/astrodict_ec.txt` | 英译中，30,094 行映射 |
| `plugins/dict/assets/astrodict_ce.txt` | 中译英，26,770 行映射 |
| `plugins/dict/assets/manifest.json` | 来源版本、文件名、字节数、行数和 SHA-256 |

词典文件采用 UTF-8、LF 换行和 TAB 分隔的两列格式。加载器先核对清单、文件类型、大小与 SHA-256，再校验 UTF-8、列数、行数、字段长度、控制字符和重复记录。解析结果按文件身份缓存，资源变化会建立新缓存代次。

## ⏰ 生命周期

词典在首次查询时校验并加载，运行期间保持只读。插件使用标准库完成本地解析，运行时资源由发行词典文件完整提供。

---

## 🩺 排障

| 现象 | 检查项 |
| --- | --- |
| 资源校验失败 | 核对三个发行资产的完整性与版本 |
| 查询结果为空 | 按回复建议缩短词汇、检查拼写，或去掉 `--exact` |
| 页码超出范围 | 直接复制回复中的“最后一页”命令 |
| 参数格式错误 | 检查引号、`--page`/`--size` 数值、重复选项与 `--` 位置 |
