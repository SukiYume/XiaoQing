# 🎲 随机选择

`choice` 从聊天中提供的列表随机选择项目。重复项可以增加对应文本的选中概率。插件支持有放回抽样和唯一项抽样。输入与结果数量均有限制。

---

## ⌨️ 命令

<!-- manifest-command-aliases:start -->
| 功能 | 推荐入口 | Manifest 等价别名 |
| --- | --- | --- |
| 随机选择 | `/选择` | `/choice` `/决定` `/抽奖` |
<!-- manifest-command-aliases:end -->

```text
/选择 <问题> <选项1> <选项2> ...
/选择 <问题> <选项1> <选项2> ... -n <数量>
/选择 <问题> <选项1> <选项2> ... -n <数量> -u
/选择 help
```

问题或选项包含空格时使用引号（Shell 风格配对规则）：

```text
/选择 "今天吃什么" "ice cream" 火锅
```

---

## 🎮 抽样规则

| 参数 | 规则 |
| --- | --- |
| 默认模式 | 有放回抽样；重复项会提高对应文本的候选权重 |
| `-n <数量>` | 一次返回多个结果，范围见“输入边界” |
| `-u`、`--unique` | 先按文本去重，再从唯一项中抽样 |
| `--` | 结束参数解析，后续内容均作为普通候选项 |

选项和回复开头的 emoji 均由系统随机源选取。选择在内存中完成，插件不产生数据文件。

---

## 🔐 输入边界

- 选项（不含问题）为 2～50 个；
- 问题长度为 1～100 个可显示字符；
- 每个选项长度为 1～200 个可显示字符；
- 整体参数长度上限为 4096 个字符；
- `-n` 接受一次 1～10 的 ASCII 整数；
- `-u` 模式要求 `-n` 不超过去重后的选项数量。

日志里只有参数长度、选项数量和抽样模式，不记录聊天文本与抽样结果。

---

## 💡 示例

```text
/选择 午饭 火锅 烤肉 日料
/选择 抽奖 小明 小红 -n 5
/选择 抽奖 小明 小红 小明 -n 2 -u
/选择 符号 -- -n -u
```

---

## 🩺 排障

| 提示 | 处理方式 |
| --- | --- |
| 参数格式错误 | 检查引号配对、`-n` 数值与参数顺序 |
| 选项数量超出范围 | 调整选项个数，范围见“输入边界” |
| `-u` 下不同选项数量不足 | 减小 `-n`，或增加不同文本的选项 |
