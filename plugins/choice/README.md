# 随机选择

在聊天中执行有界的随机选择，支持重复项加权、有放回多选，以及按文本去重后的不放回多选。

## 命令

<!-- manifest-command-aliases:start -->
| 功能 | 推荐入口 | 等价别名 |
| --- | --- | --- |
| 随机选择 | `/选择` | `/choice`、`/决定`、`/抽奖` |
<!-- manifest-command-aliases:end -->

所有入口使用完全相同的参数和权限语义：

```text
/选择 <问题> <选项1> <选项2> ...
/选择 <问题> <选项1> <选项2> ... -n <数量>
/选择 <问题> <选项1> <选项2> ... -n <数量> -u
```

问题或选项包含空格时需要加引号：

```text
/选择 "今天吃什么" "ice cream" 火锅
```

## 抽样语义

- 默认是有放回抽样，严格返回 `-n` 指定的数量；数量可以大于选项数。
- 默认模式保留重复项，因此 `/选择 午饭 火锅 火锅 日料` 会让“火锅”拥有两倍候选权重。
- `-u` 与 `--unique` 会先按文本去重，再执行不放回抽样；结果不会出现两个相同文本。
- 去重模式下，数量不能超过不同选项的数量。
- `--` 会终止选项解析；其后的 `-n`、`-u` 等文本会作为普通候选项。
- 抽样和展示 emoji 使用系统随机源；插件不持久化问题、候选项或结果。

## 边界

- `-n` 只能出现一次，并且必须是 1–10 的 ASCII 整数。
- 支持 2–50 个候选位置；问题最长 100 字，单个选项最长 200 字。
- 整条参数最长 4096 字；空文本、控制字符、未知命令选项和未闭合引号会被拒绝。
- 日志只记录长度、候选数量和模式，不记录问题、选项或抽样结果。

## 示例

```text
/选择 午饭 火锅 烤肉 日料
/选择 抽奖 小明 小红 -n 5
/选择 抽奖 小明 小红 小明 -n 2 -u
/选择 符号 -- -n -u
```

第二个示例允许同一人重复出现；第三个示例只会从“小明”“小红”两个不同文本中抽取。
