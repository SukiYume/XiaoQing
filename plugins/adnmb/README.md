# A岛匿名版浏览插件

当前实现提供公开内容浏览，以及基于插件匿名 UUID 的订阅列表管理。它不支持账号登录、Cookie 管理、发帖或回复，也不需要配置账号或 Cookie。

## 命令

- `/adnmb -t [-p 页码]`：时间线
- `/adnmb -f`：板块列表
- `/adnmb -m 板块名 [-p 页码]`：板块内容
- `/adnmb -c 串号 [-p 页码]`：串和回复
- `/adnmb -r 回复号`：单条回复
- `/adnmb -d [-p 页码]`：订阅列表
- `/adnmb -a 串号`：订阅串
- `/adnmb -e 串号`：取消订阅
- `/adnmb -h`：帮助

订阅操作只修改 A 岛 API 中与插件匿名 UUID 关联的 feed，不代表登录用户账号。图片下载有总超时、字节、MIME 和像素限制，并缓存到本地。
