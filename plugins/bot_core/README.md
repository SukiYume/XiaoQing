# bot_core

`bot_core` 是 XiaoQing 的基础管理插件，集中提供命令帮助、运行时重载、插件列表、群静音、密钥管理和指标查看能力。当前版本为 `0.2.0`。

## 命令

| 主命令 | 别名 | 权限 | 作用 |
| --- | --- | --- | --- |
| `/help [关键词]` | `/h`、`/帮助` | 所有人 | 查看全部命令，或按插件名、命令和说明搜索 |
| `/reload` | `/重载` | 管理员 | 依次重载配置和插件 |
| `/plugins` | `/插件` | 所有人 | 查看已加载的插件名称和总数 |
| `/闭嘴 [时长]` | `/shutup`、`/mute`、`/安静` | 管理员 | 在群聊中临时停止回复 |
| `/说话` | `/speak`、`/unmute` | 管理员 | 提前解除当前群的静音 |
| `/set_secret <路径> <值>` | `/setsecret`、`/设置密钥` | 全局管理员私聊 | 更新已有密钥配置 |
| `/get_secret <路径>` | `/getsecret`、`/查看密钥` | 全局管理员私聊 | 查看脱敏值或对象键名 |
| `/metrics` | `/stats`、`/性能`、`/指标` | 管理员 | 查看运行时间、调用量、成功率和慢插件 |

权限的第一层由 `plugin.json` 中的 `admin_only` 声明控制。密钥命令还会在处理函数内再次确认：请求必须来自私聊、调用者必须是 Bot 全局管理员，并且上下文必须提供 `secret_admin` 能力。

## 帮助与插件列表

`/help` 从插件管理器读取帮助文本，并按插件分组显示。带关键词时，只要插件名、命令或说明中任意一行匹配，就会保留该插件的完整分组；匹配不区分大小写。

`/plugins` 只列出当前已加载的插件名称，不推测或展示清单之外的版本信息。

## 重载

`/reload` 先调用同步的配置重载，再调用插件重载。插件重载既可以直接完成，也可以返回一个需要等待的异步任务。任一步失败都会经过统一的公开错误处理，原始异常不会直接发送给用户。

## 群静音

静音命令只在群聊中生效。空参数使用默认值 10 分钟；显式参数必须是有限正数，支持以下格式：

```text
/闭嘴          # 10 分钟
/闭嘴 30       # 30 分钟
/闭嘴 30m      # 30 分钟
/闭嘴 30min    # 30 分钟
/闭嘴 1.5h     # 90 分钟
/闭嘴 2小时    # 120 分钟
/闭嘴 30分钟   # 30 分钟
```

单位字母不区分大小写，最长为 24 小时。负数、零、`NaN`、`Infinity`、科学计数法和混合后缀会被明确拒绝，不会悄悄回退到默认时长。

`/说话` 会查询当前群的剩余静音时间：没有静音时只返回提示，存在静音时才执行解除操作。两个命令都拒绝私聊请求。

## 密钥管理

### 路径

路径由英文大小写字母、数字、下划线或连字符组成的片段构成，片段之间使用 `.` 分隔，例如：

```text
plugins.signin.sid
plugins.my-plugin.api-key
admin_user_ids
```

`set_secret` 只能更新配置中已经存在的路径，不能借此任意扩展配置结构。实际写入由 `SecretAdminService` 和 `ConfigManager` 完成；提交成功后，配置管理器负责发布变更通知，插件不会重复触发手工重载。

### 值

命令会优先把值解析为标准 JSON；解析失败时才按原始字符串保存：

```text
/set_secret plugins.demo.enabled true
/set_secret plugins.demo.retries 3
/set_secret plugins.demo.tags ["a", "b"]
/set_secret plugins.demo.options {"mode": "safe"}
/set_secret plugins.demo.token plain-text-token
```

`NaN`、`Infinity` 和 `-Infinity` 不是标准 JSON 数值，因此会按普通字符串处理，避免把非有限浮点数写入配置。

### 脱敏

命令参数不会写入普通日志。返回结果也不会显示完整值：

- 长度不超过 4 的字符串显示为 `****`；
- 更长的字符串只保留前后各 2 个字符，中间固定显示 `****`；
- 数字和布尔值显示为 `****`；
- 列表只显示元素数量；
- 对象只显示键数量，或在查询对象路径时显示最多 20 个直属键名；
- 其他类型显示为 `[hidden]`。

这是一层展示保护，不代表聊天记录适合传递长期密钥。仍应只在受控的管理员私聊中使用这些命令。

## 运行指标

`/metrics` 依赖上下文中的指标服务。服务不可用或没有返回有效摘要时，命令会明确提示未启用或无法获取数据。正常摘要包括：

- 运行时间；
- 总调用数；
- 成功率；
- 平均耗时；
- 慢调用数；
- 错误数；
- 最多 5 个最慢插件及其平均耗时。

显示层会把畸形、负数和非有限数值安全回落为零，并清理插件名称中的换行及多余空白，避免损坏的观测数据破坏回复格式。

## 文件结构

```text
bot_core/
├── __init__.py   # 包说明
├── main.py       # 命令分发与实现
├── plugin.json   # 插件清单、触发词和权限声明
└── README.md     # 本文档
```

`init()` 是插件加载器要求的统一生命周期钩子。该插件没有需要预热的状态，因此钩子有意保持无操作。

## 验证

在仓库根目录运行：

```powershell
python -m ruff check plugins/bot_core tests/plugins/test_bot_core.py
python -m pytest -q tests/plugins/test_bot_core.py `
  tests/plugins/test_internal_log_redaction.py `
  tests/plugins/test_public_error_redaction.py
```

测试覆盖命令分发、帮助过滤、静音边界、管理员能力校验、密钥脱敏、异常公开边界及指标容错。
